# Erdos_Solving

مستودع بحثي مخصص لدراسة مسائل Erdős بمساعدة الذكاء الاصطناعي، مع التركيز على **المعرفة أولاً، والبرمجيات ثانياً** وعلى قابلية التحقق وتتبع الأدلة.
Erdos_Solving = مختبر مفتوح لدراسة عملية البحث الرياضي البشري–الآلي على مسائل Erdős، من المحاولة الأولية إلى البرهان الرسمي.


## الهدف

بناء بيئة بحثية لكل مسألة تحفظ بصورة منظمة:

- نص المسألة ومصدره وسياقه.
- الحالة الرياضية الرسمية وغير الرسمية.
- الأدبيات والنتائج السابقة.
- محاولات الذكاء الاصطناعي والباحثين.
- الحسابات وcounterexamples.
- المتتاليات المرتبطة في OEIS.
- formalization في Lean عند الإمكان.
- أثر التحقق والنقد والقرارات.

## الحالة التشغيلية الحالية

> **مزامنة الحالة:** 15 أوت 2026. تعتمد هذه الحالة الرياضية على الالتزام `853a3486af63e86030e5b669266b6e0fe5e16ce8` وعلى GitHub Actions run `31872525005`، الذي اجتاز `mk_all --check` والبناء القانوني الكامل في 8741 مهمة.

- المسألة النشطة: **Erdős #678**.
- نمط العمل: **إعادة بناء برهان Cambie (2024) وإعادة تنفيذه في Lean**، وليس محاولة مستقلة عمياء.
- Claim 5: النطاقات الثلاثة، تجميع تقييماتها، وشروط عدم الصفر والهوية الطبيعية النهائية متحققة آليًا تحت فرضيات البواقي الصريحة.
- Claim 4: متحقق آليًا جزئيًا حتى الربط المقاس بواجهتي Claim 5؛ صار الفرق صريحًا بين الإحداثيات المطبّعة والممثلين الفعليين `x = 1 + z*Nx` و`y = z*Ny`.
- تحققت كثافة صناديق `x` و`y` بعد التحجيم، وتجميع الإحداثيات الخاصة والثابتة في `Claim5MediumResidues`، واشتقاق `Claim5SmallResidues` من قابلية قسمة المقياسين بالقوى الأولية المطلوبة.
- اختبار قابل للوصول عند `k = 4` ينتج الواجهتين ثم يستعمل `claim5_full_identity_of_residues` مباشرة؛ أي إن حد D3 ليس توصيلاً شكليًا.
- البناء الكامل ما زال **غير مكتمل**: تعريف المقياسين العامين `Nx,Ny`، اختيار الأوليات والفواصل، وحدود الحجم وشرط `y > x + k` هي التزامات D4.
- حالة CI: **GREEN** في التشغيل `31872525005` للالتزام الرياضي أعلاه؛ يظل حفظ أرشيف `.lake` معطّلًا، بينما تبقى ذاكرة Mathlib مفعّلة.
- الخطوة التالية الوحيدة: بناء المقاييس والاختيارات الكمية، إثبات شروط القسمة والوحدات وأطوال البحث، ثم استخراج ممثلين مفصولين بالحجم المطلوب.
